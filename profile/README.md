# gitrl-tools

Graphical git tools built on `gitg`.

- [gitrl-f](https://github.com/gitrl-tools/gitrl-f): browse the history of only the branches and tags you tick, and search it by message, author, changed lines or file.
- [gitrl-z](https://github.com/gitrl-tools/gitrl-z): browse the reflog and see on the commit graph what a `reset` to any entry would do, before you run it. Preview a rewind of one branch, or of the whole repository, to any earlier moment, and get the git commands that take you there.
