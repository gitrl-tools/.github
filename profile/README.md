# gitrl-tools

gitrl-tools holds graphical tools for git, built from gitg.

- [gitrl-z](https://github.com/gitrl-tools/gitrl-z): a `reflog` browser that shows the result of a `reset` to a `reflog` entry, before you do the reset. This helps revert changes repo-wide and time-travel to valid repo states.
- [gitrl-f](https://github.com/gitrl-tools/gitrl-f): a history browser that shows only the branches, remote branches and tags that you tick.
